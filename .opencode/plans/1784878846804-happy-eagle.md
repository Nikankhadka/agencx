# Disable Dark Mode

## Context
Dark mode (activated via OS preference or `data-theme="dark"`) doesn't look good with the pink/crimson UI. Disable it entirely for now so the app is always light mode.

## Changes

### 1. `frontend/src/styles/theme.css` (lines 144-224)
- Delete the entire dark override section: both `:root[data-theme="dark"]` block (lines 152-187) and the `@media (prefers-color-scheme: dark)` block (lines 189-224)
- Delete the comment block explaining the duplication requirement (lines 144-151)

### 2. `frontend/src/lib/brand.ts` (lines 137-155)
- Simplify `brandStyle()` - no longer need light-mode scoping since there's no dark mode. Emit a single unscoped `:root{...}` override
- Update the module docstring (lines 1-16) to remove dark mode references

### 3. `frontend/src/lib/brand.test.ts` (lines 62-71)
- Update the `brandStyle` test to expect a simple `:root{...}` override instead of the light-mode-scoped `@media` + `data-theme` selectors

## Out of scope
- Dark-surface primitives (lines 67-74 in theme.css) - harmless to keep, no runtime effect
- Adding a theme toggle UI - not asked for

## Verification
- `make test-frontend` (brand tests pass)
- `make lint-frontend` (no issues)
- `make typecheck-frontend` (no issues)
